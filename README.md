# ShieldX — AI-Powered Cybersecurity Assistant

## Project Overview
ShieldX is an Android application designed to detect potentially suspicious messages and URLs using machine learning and provide security alerts to users.

## Core Modules
- AI/ML dataset research and preprocessing
- Model training, evaluation and TensorFlow Lite conversion
- Firebase login, registration and password recovery
- Android UI and local database integration
- Notification monitoring and threat analysis
- Threat alerts, threat history, reports and settings
- Final testing, demonstration and documentation

## Technologies
- Android Studio, Java and XML
- Firebase Authentication
- Python and Google Colab
- TensorFlow Lite
- Room database
- Git and GitHub
